# CisternBirch

CisternBirch enables cloud-native, containerized workloads to scale with a distributed, event-driven architecture and a task queue engine.

CisternBirch is built to be simple and practical, focusing on doing one thing well.

**Why CisternBirch?**

- CisternBirch enables cloud-native, containerized workloads
- to scale with a distributed,
- event-driven architecture and a task

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/CisternBirch.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

CisternBirch is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
